# Quick Tutorials

[Learning Materials](../README.md)

Use the contents in each notebook to jump to a topic, or run its cells in order to follow the full example.

- [Dataset and ExperimentData](https://nbviewer.org/github/sb-ai-lab/HypEx/blob/5fd5e6dacd4da6055befbcb767386f6b9786af35/examples/tutorials/quick_tutorials/Dataset.ipynb) — assign column roles, choose a backend, and find the metrics an experiment will use.
- [ABTest](https://nbviewer.org/github/sb-ai-lab/HypEx/blob/5fd5e6dacd4da6055befbcb767386f6b9786af35/examples/tutorials/quick_tutorials/ABTest.ipynb) — compare means, choose tests for numeric and categorical metrics, and interpret the report.
- [CUPED and CUPAC](https://nbviewer.org/github/sb-ai-lab/HypEx/blob/5fd5e6dacd4da6055befbcb767386f6b9786af35/examples/tutorials/quick_tutorials/CUPED_CUPAC.ipynb) — assign roles to historical data and compare confidence intervals for both methods on one sample.
- [AATest](https://nbviewer.org/github/sb-ai-lab/HypEx/blob/5fd5e6dacd4da6055befbcb767386f6b9786af35/examples/tutorials/quick_tutorials/AATest.ipynb) — set group proportions, check categorical balance, and examine p-values across repeated splits.
- [HomogeneityTest](https://nbviewer.org/github/sb-ai-lab/HypEx/blob/5fd5e6dacd4da6055befbcb767386f6b9786af35/examples/tutorials/quick_tutorials/HomogeneityTest.ipynb) — compare numeric features and categorical distributions in existing groups.
- [Matching quick tutorial](https://nbviewer.org/github/sb-ai-lab/HypEx/blob/5fd5e6dacd4da6055befbcb767386f6b9786af35/examples/tutorials/quick_tutorials/MatchingQuick.ipynb) — check baseline imbalance, run matching, and read the effect estimate.
- [Matching in depth](https://nbviewer.org/github/sb-ai-lab/HypEx/blob/5fd5e6dacd4da6055befbcb767386f6b9786af35/examples/tutorials/quick_tutorials/Matching.ipynb) — examine plots and neighbor indices, then explore bias adjustment, common support, and distance settings.
- [Spark](https://nbviewer.org/github/sb-ai-lab/HypEx/blob/5fd5e6dacd4da6055befbcb767386f6b9786af35/examples/tutorials/quick_tutorials/SparkBackend.ipynb) — use the same experiment API on both backends and cache Spark inputs for reuse.
