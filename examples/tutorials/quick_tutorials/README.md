# Quick Tutorials

[Learning Materials](../README.md)

Use the contents in each notebook to jump to a topic, or run its cells in order to follow the full example.

- [Dataset and ExperimentData](Dataset.ipynb) — assign column roles, choose a backend, and find the metrics an experiment will use.
- [ABTest](ABTest.ipynb) — compare means, choose tests for numeric and categorical metrics, and interpret the report.
- [CUPED and CUPAC](CUPED_CUPAC.ipynb) — assign roles to historical data and compare confidence intervals for both methods on one sample.
- [AATest](AATest.ipynb) — set group proportions, check categorical balance, and examine p-values across repeated splits.
- [HomogeneityTest](HomogeneityTest.ipynb) — compare numeric features and categorical distributions in existing groups.
- [Matching quick tutorial](MatchingQuick.ipynb) — check baseline imbalance, run matching, and read the effect estimate.
- [Matching in depth](Matching.ipynb) — examine plots and neighbor indices, then explore bias adjustment, common support, and distance settings.
- [Spark](SparkBackend.ipynb) — use the same experiment API on both backends and cache Spark inputs for reuse.
