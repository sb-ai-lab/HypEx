# HypEx Learning Materials

| Section | When to use it |
| --- | --- |
| [Quick Start](https://nbviewer.org/github/sb-ai-lab/HypEx/blob/5fd5e6dacd4da6055befbcb767386f6b9786af35/examples/tutorials/QuickStart.ipynb) | Run your first A/B test, A/A test, homogeneity check, or matching analysis. All four examples run on pandas and Spark. |
| [Quick Tutorials](quick_tutorials/README.md) | Learn when to use each method, how to configure it, and how to read its reports. |
| [How-to Guides](how_to_guide/README.md) | Solve a specific problem, such as reducing metric variance with CUPED. |

The Quick Start and Quick Tutorials teach through worked examples with sample data. Each how-to guide starts with a task and walks through the inputs, code, and results. [Diátaxis](https://diataxis.fr/)

[Browse the published notebook snapshot in nbviewer](https://nbviewer.org/github/sb-ai-lab/HypEx/tree/5fd5e6dacd4da6055befbcb767386f6b9786af35/examples/tutorials/)

If you need to install HypEx, see the [project README](../../README.md#installation). The [Spark tutorial](https://nbviewer.org/github/sb-ai-lab/HypEx/blob/5fd5e6dacd4da6055befbcb767386f6b9786af35/examples/tutorials/quick_tutorials/SparkBackend.ipynb) runs the same examples on Spark and pandas.
